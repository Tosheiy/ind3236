# ind3236（自作キーボード）

左手32キー・右手36キーの分離型キーボードです。
基板（KiCad）、アクリルのサンドイッチ型ケース、3Dプリント用のボトムケース、ファームウェアを含みます。

## ディレクトリ構成

| パス | 内容 |
| --- | --- |
| `ind-assemble_L/`, `ind-assemble_R/` | メイン基板（スイッチ・マイコンを載せる基板）の KiCad プロジェクト |
| `ind-top_L/`, `ind-top_R/` | トッププレート（スイッチプレート） |
| `ind-cover_L/`, `ind-cover_R/` | マイコン部分のカバープレート |
| `ind-bottom_L/`, `ind-bottom_R/` | ボトムプレート |
| `order/ind3638/` | 発注用のガーバー・ドリルデータ（`ind-assemble_*/elecrow/` は Elecrow 向け） |
| `case/` | 3Dプリント用ボトムケース（STL / STEP）と生成スクリプト |
| `firmware/` | ビルド済みファームウェア（`ind3236v1_default.hex`） |

プレート類（top / cover / bottom）は基板データとして作っていますが、アクリル板の切り出しにも使えます（各フォルダに外形の SVG があります）。

## 部品（片手あたり）

| 部品 | 左 | 右 | 備考 |
| --- | --- | --- | --- |
| Pro Micro（USB-C） | 1 | 1 | 基板の表面に実装 |
| キースイッチ（Cherry MX 互換） | 32 | 36 | ホットスワップソケット対応 |
| ホットスワップソケット（MX 用） | 32 | 36 | 基板の裏面 |
| ダイオード（1N4148 など） | 32 | 36 | スルーホール / SMD 両対応フットプリント |
| TRRS ジャック（MJ-4PP-9） | 1 | 1 | 左右をつなぐ |
| リセットスイッチ | 1 | 1 | |
| LED（SK6812MINI-E） | 6 | 6 | 任意 |
| M2 ネジ・スペーサー | 20穴 | 19穴 | サンドイッチ型ケースを使う場合 |

キーキャップのサイズ：

- 左：1u ×24、1.25u ×5、1.5u ×1、1.75u ×1、2.25u ×1
- 右：1u ×26、1.25u ×6、1.5u ×1、2u ×1、2.25u ×1、2.75u ×1

ほかに TRRS ケーブル（4極）と USB-C ケーブルが必要です。

## 基板・プレートの発注

`order/ind3638/` 以下のフォルダ（または zip）をそのまま基板メーカーにアップロードします。
KiCad で修正した場合は、各プロジェクトを開いて「ファイル → 製造用出力 → ガーバー」から出力し直してください。

## 組み立て

1. ダイオード、ホットスワップソケット、リセットスイッチ、TRRS ジャック、（使う場合は）LED をはんだ付けします。
2. Pro Micro を取り付けます（ピンヘッダかソケットで基板の表面に）。
3. ファームウェアを書き込み、全キーが反応するか確認します。
4. トッププレートにスイッチをはめ、基板に差し込みます。
5. ケースに組み込みます（アクリルのサンドイッチ型、または下の3Dプリントケース）。

## ファームウェアの書き込み

`firmware/ind3236v1_default.hex` は Pro Micro（ATmega32U4）用のビルド済みファイルです。

1. [QMK Toolbox](https://github.com/qmk/qmk_toolbox) をインストールします。
2. QMK Toolbox で hex ファイルを選び、「Auto-Flash」にチェックを入れます。
3. Pro Micro を USB で接続し、基板のリセットスイッチを押すと書き込まれます。
4. 左右どちらの Pro Micro にも書き込みます。

## 3Dプリントケース（`case/`）

基板を入れるボトムケースです。底面は平らで、ネジ穴や柱はありません。

| ファイル | 用途 |
| --- | --- |
| `ind3236_case_L.stl` / `ind3236_case_R.stl` | スライサー用（Bambu Studio など） |
| `ind3236_case_L.step` / `ind3236_case_R.step` | Fusion 360 などでの編集用 |
| `generate_case.py` | 上のファイルを KiCad データから生成するスクリプト |

主な寸法：

- 外形：左 164.6 × 102.7 × 20.5 mm、右 188.4 × 102.7 × 20.5 mm
- 壁・床の厚さ：3 mm、基板との隙間：片側 0.7 mm
- 背面：Pro Micro の幅（約18.2 mm）で上まで開いた切り欠き（USB-C 用）
- 側面：TRRS 用の丸穴（直径 11 mm、左ケースは右側面・右ケースは左側面）
- 穴の高さは、基板の下面が床から 4 mm の位置にある前提です。基板はスペーサーなどで支えてください。

寸法を変えるときは `generate_case.py` 冒頭のパラメータを編集して実行します。

```sh
pip install -r case/requirements.txt
python3 case/generate_case.py
```

### 印刷のめやす

- 素材：PLA または PETG、ノズル 0.4 mm、レイヤー 0.2 mm
- 向き：床をプレートに付けたまま（サポート不要）
- 壁 3 周、インフィル 15〜20 %、反り防止にブリムを付ける
- 右ケース（188.4 mm）は造形範囲 180 mm 角のプリンター（Bambu Lab A1 mini など）には入りません。A1 などの大きいプリンターを使うか、分割してください。

## ロゴについて

基板のロゴ部分は、`own_making:LOGO_PLACEHOLDER`（シルクの枠と「LOGO」の文字）に置き換えてあります。
発注用ガーバーからもロゴは削除済みです。自分のロゴを入れる場合は、KiCad でこのフットプリントを差し替えてください。
